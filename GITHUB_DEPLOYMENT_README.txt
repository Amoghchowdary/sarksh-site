SARKSH GROW v25 deployment

1. Delete old website files from the GitHub Pages repository root.
2. Upload all contents inside sarksh-site-main from this ZIP.
3. Confirm GitHub Pages uses HTTPS and Enforce HTTPS is enabled.
4. Open https://www.sarksh.in/sitemap.xml and confirm only current product-first pages are listed.
5. In Google Search Console, submit sitemap.xml and request indexing for the homepage and product pages.
6. Use Google Search Console Removals for old public URLs if urgent.
